# INSTRUÇÕES UNIVERSAIS PARA A IA / EQUIPE DE CRIAÇÃO

Use este briefing para criar uma proposta de site estrategicamente coerente com a marca.

## Objetivo da execução

Transformar as informações acima em uma experiência digital profissional, responsiva, clara, persuasiva e alinhada ao posicionamento da empresa.

## Resultado esperado

Gerar:

- direção criativa
- estrutura do site
- sitemap
- seções por página
- proposta visual
- copy inicial
- direcionamento de UX/UI
- base para SEO
- stack recomendada quando necessário

## Regras obrigatórias

1. O site deve refletir a identidade da marca e não usar decisões visuais genéricas.
2. O design deve funcionar muito bem no mobile.
3. A copy deve ser clara, estratégica e alinhada ao tom da marca.
4. O site deve priorizar conversão, clareza e percepção de valor.
5. As referências visuais do cliente devem orientar o estilo, mas sem copiar.
6. Cores proibidas e estilos rejeitados devem ser respeitados.
7. O projeto deve ser escalável e fácil de manter.

## Se usar Stitch MCP

Ao usar Stitch MCP:

- interpretar este briefing como fonte principal de contexto
- gerar telas e componentes coerentes com a identidade descrita
- respeitar o estilo visual, tom de marca, sentimentos desejados e referências
- priorizar layout limpo, responsivo e orientado à conversão
- propor componentes reutilizáveis
- evitar excesso de ornamentação visual sem função estratégica

## Entregáveis recomendados

1. Resumo estratégico da marca
2. Direção visual
3. Estrutura do site
4. Wireframe textual da homepage
5. Seções principais das páginas internas
6. Copy base por seção
7. Recomendação técnica de stack
8. Checklist de deploy, domínio, métricas e manutenção
